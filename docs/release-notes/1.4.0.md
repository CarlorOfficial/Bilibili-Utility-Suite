# B站综合插件 1.4.0 更新日志

发布日期：2026-08-01

本次更新进一步优化动态订阅与直播订阅的协同处理，减少同一开播事件产生重复提醒。

## 动态通知

- 动态订阅现会跳过 B站自动生成的开播动态，避免与直播订阅的开播提醒重复。
- 转发此类开播动态时同样不会产生动态提醒。
- 普通动态正文中出现“直播了”等文字不受影响，仍会按订阅设置正常推送。
- Windows 与 Linux 版本已同步更新。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查并安装更新。
- 更新完成后请按页面提示重启插件，以加载新版本。
- 本次升级不会修改现有连接、授权、订阅、模板或群配置。
