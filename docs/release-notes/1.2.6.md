# B站综合插件 1.2.6 更新日志

发布日期：2026-07-25

本次更新为图片模式带来可视化自定义模板。发送结构与渲染图片内部字段分层配置，文字模板和既有群级覆盖配置均保持兼容。

## 图片模式自定义模板

- “插件配置 → 自定义模板”新增“文字模式 / 图片模式”切换，不再需要手动修改配置文件。
- 图片模板分为两层：第 1 层控制消息中标题、渲染图片和链接的发送顺序；第 2 层控制渲染卡片中的头图、头像、封面、正文、图片、状态与底部信息。
- 每个字段旁均提供可点击变量。文字字段可组合作者、UID、标题、正文、状态等实时数据；素材字段可直接选择主页头图、头像、封面、正文图片、转发图片、头像挂件和装扮卡片。
- 图片模式保留“渲染图片”必填提示、变量白名单校验和恢复默认操作，避免误删关键图片占位导致消息无法发送。
- 全局模板与按群覆盖继续沿用原有继承规则；现有文字模板和已保存配置无需迁移即可继续使用。

## 模板渲染

- 动态、视频、直播、直播事件、番剧更新、用户查询、直播间查询、装扮和收藏集等卡片均可按场景加载对应的图片模板。
- 图片内字段保存后会直接进入本地渲染器，媒体槽位仍按真实图片处理，不会转换为 Markdown 或公开图片链接。

## 升级须知

- 当前插件版本为 `1.2.6`。
- Windows 与 Linux 用户请分别下载对应平台的完整发布包。
- 升级不会清除框架连接、WebUI 令牌、插件主人、机器人独立数据空间、订阅或既有自定义模板。
