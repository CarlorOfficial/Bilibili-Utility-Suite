# B站综合插件 1.3.5 更新日志

发布日期：2026-07-28

## 在线更新

- 【优化】在线更新新增 GitHub 多节点自动回退能力，网络波动或单一线路不可用时可自动切换备用节点并继续传输。
- 【优化】WebUI 更新弹窗新增当前下载节点与备用节点状态，更新过程更加清晰可见。
- 【优化】调整下载重试与超时策略，减少不可用线路造成的长时间等待，提高 Windows 与 Linux 在线更新的稳定性。

## 品牌展示

- 【调整】统一 WebUI、运行提示和发行文档中的主显示名称为“B站综合插件”。
- 【兼容】英文名称 Bilibili Utility Suite 继续作为项目与发行标识，不影响原有安装目录、配置文件及业务数据。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查并安装更新。
- 更新完成后请按页面提示重启插件，以加载新版本。
- 如当前网络环境无法使用在线更新，可前往 GitHub Releases 下载对应平台的发行包后覆盖升级。
