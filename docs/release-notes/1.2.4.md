# B站综合插件 1.2.4 更新日志

发布日期：2026-07-25

本次更新修正“运行状态”的在线时长数据源，并将框架连接认证与机器人独立授权校验彻底分离，避免授权站响应期间 WebUI 长时间显示“连接中”。

## 运行状态

- “运行时长”改为读取萌卡 NT 框架返回的当前 QQ 在线起始时间，不再使用插件进程启动时间。
- 运行时长精确显示到秒，并按天、小时、分、秒自动组合，与萌卡 NT 框架保持一致。
- QQ 昵称、账号状态、收发计数和最后活动时间统一读取框架数据。
- “框架信息”下新增“插件信息：B站综合插件 1.2.4”，便于直接确认当前运行版本。
- 兼容旧版框架字段；框架未提供在线时间时会明确显示“框架未提供”，不再生成错误时长。

## 连接与授权

- 框架 IP、端口和令牌验证完成后立即进入已连接状态，每个机器人 QQ 的授权校验在后续独立执行。
- 授权站请求较慢或暂时不可用时，不再把已经连通的框架显示为“连接中”或“重试中”。
- WebUI 分别展示框架连接状态和授权校验进度，可直接区分令牌连接问题与账号授权问题。
- 多机器人 QQ 继续逐个独立校验授权；单个 QQ 的授权结果不会影响其他 QQ 的框架连接和数据空间。

## 升级须知

- 当前插件版本为 `1.2.4`。
- Windows 与 Linux 用户请选择对应平台的完整发布包进行升级。
- 升级不会清除框架连接、WebUI 令牌、插件主人和机器人独立数据。
