# B站综合插件 1.2.3 更新日志

发布日期：2026-07-25

本次更新修复 WebUI 功能开关页面的群号选择问题，统一下拉显示值与实际提交群号的处理。

## 功能开关

- 修复从群号搜索下拉菜单选择“群号 · 群名”后，点击“载入配置”仍提示“请输入有效群号”的问题。
- 下拉菜单继续显示群名称，载入和保存时自动提取真实群号，不再要求手动删除群名称和分隔符。
- 同时兼容手动输入纯群号、输入群号或群名筛选后选择下拉项两种操作方式。
- 切换机器人 QQ 后仍会按当前机器人重新加载群列表，机器人之间的群配置保持独立。

## 升级须知

- 当前插件版本为 `1.2.3`。
- Windows 与 Linux 用户请选择对应平台的完整发布包进行升级。
- 升级不会清除框架连接、WebUI 令牌、插件主人和机器人独立数据。
