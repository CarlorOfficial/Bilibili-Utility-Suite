# B站综合插件 1.0.6 更新日志

发布日期：2026-07-21

本次更新完善 Windows 免安装运行环境、自定义模板变量、直播实时数据与多 QQ 独立登录安全，并调整 WebUI 导航和项目展示。

## Windows 运行环境

- Windows 免安装包内置完整 VC143 x64 运行库。
- 修复部分电脑缺少 `VCRUNTIME140_1.dll`、`MSVCP140_1.dll` 或 `MSVCP140_2.dll` 而无法启动的问题。

## 自定义模板与直播数据

- 自定义模板新增用户总播放数、直播粉丝团、舰长开播/下播统计和收藏集内容变量。
- 直播期间通过房间 WebSocket 实时更新粉丝团人数。
- 收藏集详情兼容仅返回 `tab_lottery_id` 的数据。

## 数据与来源安全

- 所有 B站登录态接口继续按机器人 QQ 独立使用扫码 Cookie，账号数据互不串用。
- 装扮预售号码在没有可靠公共接口时显示“暂未获取”，不使用预约人数或库存替代。

## WebUI 与项目展示

- Gitee 项目横幅改用 WebUI Logo，移除固定版本号并调整卡片与文字居中。
- “功能开关”和“自定义模板”改为左侧一级菜单，替代原“插件配置”二级切换。

## 升级须知

- 当前插件版本为 `1.0.6`。
- Windows 与 Linux 外发包均为签名和加固后的二进制包，不包含插件功能源码。
