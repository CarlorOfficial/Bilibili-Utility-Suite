# B站综合插件 1.2.5 更新日志

发布日期：2026-07-25

本次更新修复普通动态推送缺少标题的问题，并兼容已经保存的旧版默认动态模板。

## 动态推送

- 恢复普通动态标题读取，可从动态详情字段和列表基础字段识别发布者填写的标题。
- 普通动态文字模板新增 `【动态标题】` 变量，默认显示在作者提示与正文之间。
- 动态本身未填写标题时，该位置自动留空，不会把网页通用标题误当成动态标题。
- 已保存且未自定义修改的旧版默认动态模板会自动补齐标题位置，无需手动恢复默认。
- 用户自行修改过的动态模板保持原样，不会被升级过程强制覆盖。

## 升级须知

- 当前插件版本为 `1.2.5`。
- Windows 与 Linux 用户请选择对应平台的完整发布包进行升级。
- 升级不会清除框架连接、WebUI 令牌、插件主人、机器人独立数据或自定义模板。
