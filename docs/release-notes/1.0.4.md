# B站综合插件 1.0.4 更新日志

发布日期：2026-07-20

本次更新重点完善文字模式的媒体内容、B站扫码登录流程，并统一每个机器人 QQ 的独立登录策略。

## 文字与图片消息

- 文字模式支持在回复中发送动态原图、视频封面和直播封面。
- 修复框架图片上传返回较慢时，文字模式原图被提前丢弃的问题。

## B站扫码登录

- 修复扫码登录无法生成或发送二维码的问题。
- 修复取消扫码登录时误删既有登录凭据的问题。

## 登录策略

- 移除监控模式相关指令。
- 所有 B站功能强制使用当前机器人 QQ 的独立扫码登录态，避免账号和数据串用。

## 升级须知

- 当前插件版本为 `1.0.4`。
- Windows 与 Linux 用户升级后需要按机器人 QQ 分别完成 B站扫码登录。
