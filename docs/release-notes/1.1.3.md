# B站综合插件 1.1.3 更新日志

发布日期：2026-07-22

本次更新解决重新扫码登录后回放历史动态、机器人之间互相触发和 WebUI 日志无法稳定复制的问题，并统一全群提醒协议和消息模板细节。

## 订阅基线与历史消息

- 用户重新扫码登录 B站账号后，静默重建当前 QQ 名下的动态、直播、番剧与 Bark 订阅基线。
- 登录期间或更早的历史动态不再被补发。
- 订阅游标失效时只记录当前最新动态，不回放历史内容。

## 框架消息与机器人隔离

- 全群动态和全群直播按照萌卡 NT 官方消息段规范使用 `at` 类型及 `uin=all`，文字与图片模式均适配。
- 忽略当前机器人及同一框架内其他机器人发送的消息，避免互相触发指令、链接解析和扫码登录循环。

## WebUI 运行日志

- 暂停日志后同时停止轮询和 DOM 替换，选中的日志内容不会再被刷新取消。
- 恢复日志后一次性同步暂停期间产生的新日志。

## 消息模板与图片渲染

- 文字模式图片按自定义模板变量位置插入，分割线固定在最终链接之前。
- 图片模式顶部使用 UP 主 B站主页头图，并修正裁切黑边、偏移和变形。

## 验证结果

- Windows：11/11 项自动测试通过。
- Linux：10/10 项自动测试通过。
- 双平台通过签名、外发包敏感文件审计和 WebUI 启动冒烟验证。

## 升级须知

- 当前插件版本为 `1.1.3`。
- 继续使用纯文字与图片消息，不使用 Markdown。
- 全群提醒协议依据：[萌卡 NT 消息段文档](https://mknt.net/guide/message-segments.html)。
