# B站综合插件 1.2.9 更新日志

发布日期：2026-07-26

## 账号授权体验优化

- 【优化】缩短启动后的账号授权准备时间：授权通过后会优先完成该账号的运行初始化，减少等待感。
- 【优化】有效期与账号运行信息改为后台同步，不再阻塞后续机器人账号的授权处理。
- 【优化】多机器人场景下继续按账号隔离校验与运行状态，一个账号的授权同步不会影响其他账号接入框架。
- 【优化】未通过授权时的自动重试响应更及时，框架连接状态与授权状态保持独立展示。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查更新并完成升级。
- 完成升级后重新启动插件，即可使新的授权体验优化生效。
