# B站综合插件 1.1.1 更新日志

发布日期：2026-07-22

本次更新优化 B站动态获取与详情补全速度，并提高图片上传失败时文字和已上传图片的兜底可靠性。

## 动态获取与内容补全

- 最新动态改用空间动态首屏，并按需使用详情或 Opus 接口补全内容。
- 动态详情与列表数据合并时保留正文、动态原图、视频封面、作者和转发信息。
- 移除重复的用户资料请求，减少动态查询等待时间。

## 查询性能

- 桌面动态接口返回空首屏时执行 100、200、400 毫秒有限重试，避免长时间等待。
- 数字 UID 使用快速查询路径，并在运行日志记录耗时、正文长度和图片数量。

## 图片与文字兜底

- 图片上传超时后不再让文字兜底随主 WebSocket 一起丢失。
- 图片上传 12 秒快速失败后，使用独立短连接发送文字和已上传图片段，再恢复主通道。

## 升级须知

- 当前插件版本为 `1.1.1`。
- 继续使用纯文字与图片消息模式，不使用 Markdown。
