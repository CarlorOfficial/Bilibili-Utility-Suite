# B站综合插件 1.0.8 更新日志

发布日期：2026-07-21

本次更新加入跨主机图片托管能力，统一二维码、动态封面和图片模式的投递链路，并补齐 Windows 运行依赖。

## 图片托管与跨主机投递

- 内置官方图片托管，远程框架可通过公网 URL 接收插件图片。
- 支持 EasyImage 2.0、Lsky Pro v2、Chevereto、SM.MS、通用自定义 API 和旧版反向代理兼容模式。
- 框架与插件同机时优先使用本地文件路径，跨主机时按所选图床上传。
- 二维码、动态封面和图片模式统一使用同一套图片投递链路。

## Windows 运行环境

- 外发包补齐 Microsoft VC143 x64 应用本地运行库，降低缺少 `MSVCP140.dll`、`VCRUNTIME140.dll` 等依赖导致的启动失败。

## 安全与验证

- 官方图片托管接口和凭据不在 WebUI、配置或日志中显示。
- Windows 11/11、Linux 10/10 项自动测试通过。
- 双平台通过签名校验、源码与敏感信息审计、官方图床真实上传测试、WebUI/API 冒烟测试和最终包启动验证。

## 升级须知

- 当前插件版本为 `1.0.8`。
- 远程框架环境应在“框架连接”页面选择官方内置或适配的自定义图床。
