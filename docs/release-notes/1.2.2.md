# B站综合插件 1.2.2 更新日志

发布日期：2026-07-24

本次更新重构 Windows 与 Linux 的在线更新下载链路，解决 Gitee 或 CDN 连接中途停滞时进度条长期卡住、只能重启程序重新下载的问题。

## 在线更新可靠性

- 更新下载连续 15 秒没有收到新数据时自动中断当前连接，不再无限等待。
- 单个更新文件最多自动尝试 3 次，并在 WebUI 中显示中断原因与当前重试次数。
- 重试时从已下载位置断点续传，避免大体积更新包反复从零开始；下载源不支持断点时会安全地重新下载。
- 更新请求关闭 HTTP/2 复用并使用独立连接，降低代理、网关或 CDN 链路异常造成的长时间假连接。
- 下载完成后继续执行原有 SHA-256 与 ECDSA P-256 签名校验，校验失败不会安装。

## 验证结果

- Windows：13 项自动测试通过，包含断流、超时、重试及 Range 断点续传故障注入测试。
- Linux：12 项自动测试通过，包含同等的断点续传故障注入测试。
- Windows 外发包通过启动冒烟测试，并完整携带 MSVC 与 UCRT 应用本地运行库。
- Linux 外发包通过 PIE、RELRO、BIND_NOW、敏感字符串、文件哈希与源码泄漏审计。

## 升级须知

- 当前插件版本为 `1.2.2`。
- Windows 与 Linux 用户分别下载对应平台的完整发布包。
- 升级后无需重新配置框架连接、WebUI 令牌、插件主人或机器人独立数据空间。
