# B站综合插件 1.2.8 更新日志

发布日期：2026-07-25

## 更新体验与传输可靠性

- 【升级】更新中心采用结构化发行说明渲染，完整保留版本文档的层级、列表、链接和代码格式，便于快速阅读更新内容与升级指引。
- 【优化】重构更新任务的传输状态反馈机制，兼容分块传输及未提供文件长度的下载源，进度界面可持续反映真实下载活动。
- 【优化】增强弱网恢复策略：扩展连接等待窗口与自动重试范围，并持久化已完成的下载片段，降低临时网络抖动导致更新失败或重复下载的概率。
- 【优化】更新过程使用独立的高频状态通道，提升进度展示的连续性，同时避免影响控制台的常规数据刷新。

## 升级说明

- Windows 与 Linux 用户均可在控制台完成在线升级；网络受限环境可下载对应平台的完整发行包进行覆盖安装。
