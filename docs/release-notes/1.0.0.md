# B站综合插件 1.0.0 更新日志

发布日期：2026-07-18

这是 B站综合插件萌卡 NT 版的首次正式发布，提供 Windows 与 Linux 运行版本，并建立独立授权与 WebUI 配置基础。

## 首次发布

- 正式提供 Windows 与 Linux 外发版本。
- Linux 版加入 WebUI 配置端，程序启动后会输出访问 IP、端口和管理令牌。

## 授权与运行稳定性

- 修复部分 Windows 用户在 QQ 未授权时启动程序发生闪退的问题。
- 未授权 QQ 使用轻量待授权状态，不初始化业务数据库和监控模块。
- 程序窗口与框架连接保持运行，每 30 秒为未授权 QQ 独立重试授权。
- 未授权状态不向 QQ 发送提示，也不会影响同一框架内其他已授权 QQ。

## 升级须知

- 当前插件版本为 `1.0.0`。
- 每个 QQ 的授权状态和业务数据相互独立。
