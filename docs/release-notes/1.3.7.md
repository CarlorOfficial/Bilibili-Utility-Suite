# B站综合插件 1.3.7 更新日志

发布日期：2026-07-28

本次更新进一步完善运行状态信息展示，让机器人、框架、插件与服务环境的运行信息更加完整、清晰。

## 运行状态

- 新增框架版本信息展示，框架名称与实际运行版本会合并显示。
- 新增服务系统与系统架构信息，便于快速确认当前运行环境。
- 调整状态信息布局，将机器人状态、插件版本、服务资源与网络流量分区呈现。
- 运行时长继续采用框架账号的真实在线时长，并精确显示到秒。
- 接收与发送消息数量使用本地化数字格式显示，较大数值更易阅读。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查并安装更新。
- 更新完成后请按页面提示重启插件，以加载新版本。
- 本次升级不会修改现有连接、授权、订阅或群配置。
