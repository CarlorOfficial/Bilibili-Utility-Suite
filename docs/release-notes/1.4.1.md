# Bilibili Utility Suite（B站综合插件）1.4.1 更新日志

发布日期：2026-08-01

本次更新统一了动态查询与订阅通知的内容筛选规则，并改进框架连接异常时的状态反馈。

## 动态查询

- “最新动态”会跳过 B站自动生成的开播动态，继续返回下一条可查看的普通动态。
- 转发的开播动态同样会被正确识别，避免与直播提醒产生重复内容。
- 手动查询与订阅通知现采用一致的筛选规则，普通图文、视频及其他动态不受影响。

## 框架连接

- 改进框架令牌认证失败时的结果识别，减少认证失败被误报为连接超时的情况。
- 优化框架在返回认证结果后立即断开连接时的兼容性，便于根据实际原因调整连接配置。

## 升级须知

- 当前插件版本为 `1.4.1`。
- Windows 与 Linux 用户可通过 WebUI 在线更新，或从 GitHub Releases 下载对应平台的完整发布包。
- 升级会保留现有连接、授权、订阅、模板及群配置。
- 如果框架端明确提示认证失败，请从框架插件服务页面重新复制当前完整令牌，并在插件“框架连接”页面保存一次。
