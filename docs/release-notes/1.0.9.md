# B站综合插件 1.0.9 更新日志

发布日期：2026-07-22

本次更新解决扫码登录二维码发送期间的框架动作排队与 WebSocket 重连问题，并统一异步图片操作的轮询避让。

## 扫码登录二维码

- 修复发送“扫码登录账号”时，提示消息与账号轮询并发导致框架动作排队、超时和 WebSocket 重连的问题。
- 二维码图片上传期间暂停插入账号轮询，收到动作回执后自动恢复。
- 二维码上传等待窗口调整为 120 秒，适配图床和远程框架网络波动。

## 异步任务调度

- Linux 同步修复二维码发送期间的 WebSocket 断开重连问题。
- 所有未完成的异步消息发送和图片上传统一纳入轮询避让，减少同一连接上的动作阻塞。

## 验证结果

- Windows OLLVM 构建及 11 项自动测试通过，并验证生产框架图片上传接口可正常返回图片标识。
- Linux Release 10 项自动测试、WebUI 冒烟测试和外发包安全审计通过。

## 升级须知

- 当前插件版本为 `1.0.9`。
