# B站综合插件 1.3.9 更新日志

发布日期：2026-07-29

本次更新重点改善多端同时在线时的私聊消息处理稳定性，避免同一条消息被重复响应。

## 私聊消息

- 修复机器人 PC 端同时在线时，部分私聊消息可能触发两次推送和两次回复的问题。
- 优化多端同步场景下的消息一致性判断，同一条框架事件只会进入一次业务处理。
- 连续发送内容相同但实际属于不同消息的指令仍会分别响应，不影响正常连续操作。
- Windows 与 Linux 版本已同步更新私聊处理行为。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查并安装更新。
- 更新完成后请按页面提示重启插件，以加载新版本。
- 本次升级不会修改现有连接、授权、订阅、模板或群配置。
