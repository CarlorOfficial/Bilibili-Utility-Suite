# B站综合插件 1.1.0 更新日志

发布日期：2026-07-22

本次更新重构 WebSocket 消息处理，解决图片上传和扫码二维码等待框架回包时的接收阻塞、迟到回包与日志停滞问题。

## WebSocket 消息处理

- 修复图片上传和扫码登录二维码等待框架回包时，WebSocket 接收回调发生自阻塞的问题。
- 修复 `upload_group_image` 超时后回包迟到、运行日志停滞和框架重连的问题。
- 框架消息改为队列串行处理，等待图片上传结果时不再阻塞 WebSocket 收包。
- Windows 与 Linux 使用一致的消息队列处理方式，减少图片请求期间的消息堆积和连接异常。
