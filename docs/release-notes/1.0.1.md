# B站综合插件 1.0.1 更新日志

发布日期：2026-07-20

本次更新为 Windows 与 Linux 统一加入首次运行 WebUI 初始化流程，并建立在线更新入口。

## WebUI 与初始化

- Windows 首次运行时可配置 WebUI 端口和管理令牌，完成后在网页端管理插件。
- Linux 重构首次运行的 WebUI 配置流程，统一初始化信息与启动提示。

## 在线更新

- Windows 与 Linux WebUI 均新增在线检查和下载插件更新的功能。

## 升级须知

- 当前插件版本为 `1.0.1`。
- 首次运行需完成 WebUI 端口与管理令牌初始化。
