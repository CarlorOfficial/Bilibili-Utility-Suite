# B站综合插件 1.0.5 更新日志

发布日期：2026-07-21

本次更新统一优化 WebUI 管理员入口与在线更新弹窗，并调整版本升级判定规则。

## 管理员入口

- 右上角管理员入口加入头像账户菜单、个人资料、更新授权和退出登录。
- Windows 与 Linux WebUI 使用一致的账户操作布局。

## 在线更新体验

- 在线更新弹窗采用萌卡 NT 控制台同款设计，仅保留“取消”和“立即下载”。
- 同版本或较旧版本统一提示“当前已是最新版本”。

## 更新策略

- 在线更新仅允许升级到更高版本，不再提供同版本覆盖更新。

## 升级须知

- 当前插件版本为 `1.0.5`。
- Windows 与 Linux 用户分别下载对应平台的完整发布包。
