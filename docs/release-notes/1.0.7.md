# B站综合插件 1.0.7 更新日志

发布日期：2026-07-21

本次更新提高慢网络下图片上传和扫码登录的稳定性，并加强连接配置保存、暂停与重连的生命周期管理。

## 图片上传与框架连接

- 图片上传等待时间与框架完整上传链路对齐，避免二维码和图片模式在冷启动或慢网络下提前超时。
- 图片上传期间暂停机器人列表轮询，真正超时后自动重建框架连接，避免 `get_bot_list` 连锁超时。
- 上传或查询等待期间执行暂停、保存连接配置时，不再销毁正在运行的对象。

## 配置与运行状态

- 连接配置先成功加密或持久化，再切换运行实例。
- 连续暂停、启动和保存操作以最后一次操作为准。
- Windows 首次运行说明统一为 WebUI 固定监听 `127.0.0.1`，仅配置端口和管理令牌。

## 验证结果

- Windows：10/10 项自动测试通过。
- Linux：9/9 项自动测试通过。
- 双平台通过签名校验、源码泄露审计、WebUI/API 冒烟测试和最终压缩包启动验证。

## 升级须知

- 当前插件版本为 `1.0.7`。
- 外发包不包含插件功能源码、用户配置和发布私钥。
