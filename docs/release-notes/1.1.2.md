# B站综合插件 1.1.2 更新日志

发布日期：2026-07-22

本次更新修复文字模板中的图片位置、图片模式动态卡资源加载，以及渲染卡片右上角装饰对齐问题。

## 文字模式模板

- 按自定义模板变量位置组合正文、动态图片和视频封面，不再把图片固定追加到消息末尾。
- 旧版模板缺少【动态图片】或【转发_动态图片】时自动补齐，不破坏已保存的其他自定义内容。

## 图片模式渲染

- 动态卡恢复顶部头图和正文图片。
- 无独立头图时使用视频封面或正文首图回退。
- 增强 B站图片下载兼容性，支持跳转、来源校验、超长图和移除失效转换参数后重试。
- 右上角装饰编号与挂件共用中心线并作为一组居中，修复编号和图案偏移。

## 升级须知

- 当前插件版本为 `1.1.2`。
- 继续使用纯文字与图片消息，不使用 Markdown。
