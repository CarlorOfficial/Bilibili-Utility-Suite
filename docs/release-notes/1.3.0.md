# B站综合插件 1.3.0 更新日志

发布日期：2026-07-26

## 授权状态同步优化

- 【修复】完善运行期间的授权状态复核，授权站记录变更可更及时地同步至对应机器人账号。
- 【修复】修正授权详情异常时可能继续显示有效状态的问题，授权撤销、记录缺失、状态冻结或绑定不一致时会更新该账号的运行状态。
- 【优化】网络短暂波动期间增加有限的重试保护，降低临时网络异常带来的误停用概率。

## 多账号运行优化

- 【优化】多机器人环境下的授权状态独立维护；单个账号状态变化不会影响其他正常账号继续运行。
- 【优化】WebUI 的账号授权状态与后台运行状态保持一致，便于及时确认处理结果。

## 升级说明

- Windows 与 Linux 用户均可通过 WebUI 检查更新并完成升级。
- 升级完成后重启插件，即可启用新的授权状态同步逻辑。
