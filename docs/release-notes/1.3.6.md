# B站综合插件 1.3.6 更新日志

发布日期：2026-07-28

本次更新完善群订阅通知策略，支持按订阅对象精细控制提醒方式，并加入共享的每日全体消息额度管理。

## 全群通知设置

- 动态与直播订阅新增独立的全体消息通知开关，既可按 UID 或 B站昵称配置，也可批量应用到本群全部同类订阅。
- 新增全局默认与单群覆盖两级每日全体消息次数上限；支持禁止、不限次数及指定次数三种策略。
- 动态和直播共用本群当日额度。达到上限后，消息会自动降级为普通提醒，正文与图片仍会继续发送。
- 直播全体消息通知仅应用于开播提醒，下播总结不会触发全体消息。
- WebUI 新增全群通知设置面板，可查看当前群的额度来源、当日使用量及各订阅的通知状态。

## 群待办兼容

- 动态与直播订阅已加入独立的群待办配置，并支持单项与批量调整。
- 当前萌卡 NT 插件接口尚未开放原生群待办投递能力；在接口可用前，相关提醒会保持普通消息投递，不影响订阅内容送达。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查并安装更新。
- 更新完成后请按页面提示重启插件，以加载新版本。
- 原有订阅与群配置会自动兼容；未单独设置的群默认继承全局全体消息次数上限。
