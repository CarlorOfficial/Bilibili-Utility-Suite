# B站综合插件 1.3.8 更新日志

发布日期：2026-07-29

本次更新聚焦动态内容的视觉还原与消息排版，使文字模式中的表情、正文和预览图片更贴近 B站原始内容。

## 动态消息体验

- 文字模式现可识别动态文案中的 B站表情，并转换为适合消息阅读的图片内容。
- 表情图片会按照原文出现顺序插入文字之间，不再统一堆放到消息末尾。
- 表情转换失败时会保留原始表情文字，避免正文内容缺失。

## 图片显示

- 动态、视频及查询结果中的预览图片保持原始宽高比显示，减少裁切、拉伸和变形。
- 普通正文图片继续保留原始清晰度；仅行内表情会等比调整为适合阅读的尺寸。
- Windows 与 Linux 的文字和图片消息行为已统一。

## 升级说明

- Windows 与 Linux 用户均可在 WebUI 中检查并安装更新。
- 更新完成后请按页面提示重启插件，以加载新版本。
- 本次升级不会修改现有连接、授权、订阅、模板或群配置。
