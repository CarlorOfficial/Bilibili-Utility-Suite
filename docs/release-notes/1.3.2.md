# B站综合插件 1.3.2 更新日志

发布日期：2026-07-26

## 消息路由

- 【修复】优化多账号场景下的消息来源识别，人工使用机器人账号发送的指令可正常触发插件功能。
- 【修复】插件自身发送内容仍会自动隔离，避免消息回流及多个机器人之间重复触发。

## 账号状态同步

- 【优化】插件运行账号改为跟随框架实时在线状态，仅对当前在线账号执行授权验证与功能初始化。
- 【修复】账号离线或从框架移除后，插件会同步清理对应运行状态和授权展示，避免保留已失效的账号记录。
- 【优化】框架账号新增、上线、离线与移除均可在后续同步中自动生效。

## 升级说明

- Windows 与 Linux 用户均可通过 WebUI 检查更新并完成升级。
- 升级完成后重启插件即可生效。
